# ربات فروشگاهی متصل به irMarket

ربات تلگرامی که محصولات دیجیتال رو از طریق [irMarket Buyer API](https://api.irmarket.store/buyer/docs)
می‌خره و به کاربران خودت می‌فروشه. کیف پول کاربران فعلاً **آزمایشی** است
(بدون درگاه پرداخت واقعی) — هر کاربر می‌تونه یک‌بار اعتبار تستی رایگان بگیره.

## نصب سریع با یک دستور (نصب یا بروزرسانی)

روی سرور اوبونتو/دبیانت این رو بزن:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/Aziz-dev22/v2ray-sub-template/main/install.sh)
```

این اسکریپت:
- بار اول: پیش‌نیازها رو نصب می‌کنه، پروژه رو کلون می‌کنه، venv می‌سازه، وابستگی‌ها
  رو نصب می‌کنه، **توکن ربات، آیدی ادمین‌ها و کلید API irMarket رو ازت می‌پرسه**
  و به‌عنوان سرویس `systemd` (اجرای دائمی + استارت خودکار بعد از ریبوت) بالا می‌آره.
- دفعه‌های بعد: همون دستور رو دوباره بزن — کد از GitHub بروزرسانی می‌شه،
  وابستگی‌ها آپدیت می‌شن و سرویس ری‌استارت می‌شه؛ فایل `.env` (توکن‌ها) دست‌نخورده می‌مونه.

> اگه سوال‌هایی که اسکریپت می‌پرسه رو یه بار جواب بدی، توی `.env` ذخیره می‌شه
> و در بروزرسانی‌های بعدی دیگه ازت پرسیده نمی‌شه.

## امکانات

- نمایش لیست محصولات با قیمت شما (`price_usd` × مارک‌آپ دلخواه)
- خرید با کسر از کیف پول داخلی + صدا زدن `/api/buyer/purchase`
- ریفاند خودکار در صورت شکست خریheد
- تاریخچه سفارش‌ها با وضعیت زنده (پول و تحویل)
- دریافت خودکار آپدیت سفارش از طریق Webhook (`order.updated`) + اعلان به کاربر در تلگرام
- پنل ادمین: آمار فروش، شارژ دستی کیف پول کاربران، ثبت/چرخش Webhook، لیست سفارش‌های اخیر

## نصب دستی (بدون اسکریپت)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

سپس `.env` رو پر کن:

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `ADMIN_TELEGRAM_IDS` | آیدی عددی ادمین‌ها، با کاما جدا |
| `IRMARKET_API_KEY` | کلید `anb_...` که از ادمین irMarket گرفتی |
| `PRICE_MARKUP` | ضریب سود شما روی `price_usd` |
| `DEMO_CREDIT_AMOUNT` / `DEMO_CREDIT_COOLDOWN_HOURS` | تنظیمات اعتبار آزمایشی |
| `WEBHOOK_PUBLIC_URL` | آدرس عمومی HTTPS سرور شما (اختیاری، بدون این فقط با poll کار می‌کنه) |

## اجرا

```bash
python3 main.py
```

این هم پولینگ ربات تلگرام رو بالا می‌آره و هم یک سرور FastAPI روی
`WEBHOOK_HOST:WEBHOOK_PORT` که مسیر `/webhook/irmarket` رو برای دریافت
کال‌بک‌های irMarket گوش می‌ده.

### ثبت Webhook (اختیاری ولی پیشنهادی)

اگه سرور شما پشت یک دامنه‌ی HTTPS واقعیه (یا با ngrok/Cloudflare Tunnel تانل
زدی)، از پنل ادمین ربات (`/admin` → «تنظیم Webhook») آدرس رو بفرست؛ ربات
خودش `/api/buyer/webhook` رو صدا می‌زنه، secret رو ذخیره می‌کنه و از اون به
بعد به‌جای poll کردن، آپدیت سفارش‌ها آنی به کاربر تلگرام اطلاع داده می‌شه.

بدون webhook هم مشکلی نیست: هر بار کاربر روی یک سفارش «در حال پردازش» کلیک
کنه، ربات خودش با `/api/buyer/orders/{id}` وضعیت تازه رو می‌گیره.

## ساختار پروژه

```
install.sh             اسکریپت نصب/بروزرسانی خودکار با یک دستور
config.py           تنظیمات از .env
database.py          لایه SQLite (کاربران / کیف پول / سفارش‌ها / تنظیمات)
irmarket_client.py    wrapper روی API irMarket
helpers.py            محاسبه قیمت، فرمت‌دهی
bot.py                همه‌ی منطق ربات تلگرام (منوها، خرید، پنل ادمین)
webhook_server.py      دریافت‌کننده webhook با تایید امضای HMAC
main.py                اجرای هم‌زمان ربات + وب‌سرور
```

## انتشار در گیت‌هاب

```bash
cd irmarket-bot
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/Aziz-dev22/v2ray-sub-template.git
git push -u origin main
```

فایل `.env` و `venv/` به لطف `.gitignore` هرگز پوش نمی‌شن، پس توکن‌هات لو نمی‌ره.

`install.sh` از قبل روی همین ریپو تنظیم شده، پس بعد از پوش همون دستور نصب یک‌خطی بالا مستقیم کار می‌کنه.

## نکات امنیتی

- کلید `IRMARKET_API_KEY` هرگز نباید در کلاینت یا در پیام‌های تلگرام لو بره.
- بدنه‌ی هر webhook با `HMAC-SHA256(secret, body)` تایید می‌شه؛ درخواست‌های
  بدون امضای معتبر با ۴۰۱ رد می‌شن.
- چون کیف پول فعلاً آزمایشیه، قبل از رفتن به پروداکشن با کاربران واقعی، حتماً
  یک درگاه پرداخت واقعی (زرین‌پال و غیره) یا شارژ دستی توسط ادمین جایگزین
  اعتبار رایگان کن.
